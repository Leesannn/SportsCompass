## 2. 프로젝트 개요

### 프로젝트명

**나침 — 스포츠 커리어 나침반**

### 프로젝트 소개

예비·현직 스포츠 지도자가 자격과 관심 종목, 희망 지역을 바탕으로 활동 방향을 살펴볼 수 있도록 지원합니다. 기관별 운영 프로그램, 지역별 자격 취득 현황, 시험 정보를 함께 제공하고, 기관의 단기 대타 모집과 지도자의 지원을 연결합니다.

| 주요 사용자 | 제공 가치 |
|---|---|
| 자격 보유 지도자 | 보유 자격과 희망 조건에 맞는 기관 탐색, 대타 공고 확인 및 지원 |
| 자격 취득 준비자 | 관심 종목에 따른 자격 방향 탐색, 시험 정보 및 학습 정보 확인 |
| 체육시설·기관 담당자 | 프로그램 현황 비교, 대타 모집 공고 등록 및 지원자 관리 |

### 프로젝트 필요성 및 배경

- 프로그램·기관 정보와 지도자 자격 정보가 분산되어 있어, 개인에게 맞는 활동 기회를 찾기 위해 여러 자료를 비교해야 합니다.
- 자격 취득 준비자는 관심 종목뿐 아니라 지역의 프로그램 현황도 함께 살펴볼 수 있는 정보가 필요합니다.
- 기관은 지도자 부재 시 모집 조건을 안내하고 지원자를 관리할 수 있는 창구가 필요합니다.
- 지역·종목별 자료를 일관된 기준으로 정리하면 프로그램 운영과 진로 탐색을 위한 참고 정보를 제공할 수 있습니다.

### 프로젝트 목표

1. 스포츠 프로그램과 자격 취득 데이터를 통합하여 정보 탐색 편의를 높입니다.
2. 자격 보유 여부와 관심 조건에 따른 맞춤 추천을 제공합니다.
3. 지역·종목별 프로그램과 자격 취득 현황을 비교할 수 있도록 지원합니다.
4. 대타 공고 등록, 지원, 지원자 관리 및 평가 기능을 제공합니다.
5. 시험 정보와 커뮤니티를 통해 학습 및 정보 공유를 지원합니다.

### 기대효과 — 정량적 측면

현재 확인된 운영 성과 수치는 없습니다. 아래 효과는 향후 실제 이용·운영 데이터를 수집하여 측정할 수 있습니다.

| 기대효과 | 추후 측정에 필요한 데이터 | 측정 가능한 지표 |
|---|---|---|
| 정보 탐색 시간 단축 | 동일한 정보 탐색 과제의 서비스 이용 전후 소요 시간, 이용 로그 | 평균 탐색 소요 시간 변화 |
| 맞춤 추천 활용 향상 | 추천 조회, 상세 페이지 이동, 실제 문의·지원 여부 | 추천 활용률, 문의·지원 전환율 |
| 대타 모집 시간 단축 | 공고 등록·채용 확정 시점, 모집 인원 및 확정 인원 | 평균 충원 소요 시간, 충원율 |
| 강사 부재에 따른 수업 공백 감소 | 휴강 사유, 대타 근무 완료 내역, 전체 수업 내역 | 강사 부재 휴강률 변화 |
| 프로그램 운영 효율 개선 | 실제 정원·신청·등록·출석 데이터, 운영 조정 이력 | 정원 충족률, 대기 인원, 참여율 변화 |
| 데이터 정리 업무 부담 감소 | 동일 자료의 수작업·시스템 처리 시간, 검수 및 수정 내역 | 처리 시간 변화, 오류 수정 비율 |

위 지표 중 추천 전환, 채용 확정 시점, 실제 출석 등은 추가 기록 또는 외부 기관 데이터 연계가 필요합니다. 성과 비교 시 같은 기간·업무 범위·대상 조건을 적용해야 합니다.

### 기대효과 — 정성적 측면

- **정보 접근성 향상:** 분산된 프로그램·자격·시험 정보를 함께 제공하여 탐색의 어려움을 줄일 수 있습니다.
- **진로 및 활동 방향 설정 지원:** 개인의 관심과 자격 조건을 지역 프로그램 현황과 함께 검토하도록 도울 수 있습니다.
- **기관의 의사결정 지원:** 프로그램 운영과 지도자 모집을 검토할 때 활용할 참고 자료를 제공할 수 있습니다.
- **지역별 활동 여건 이해:** 지역·종목별 차이를 비교하여 추가 조사나 지원 검토가 필요한 영역을 찾는 데 도움을 줄 수 있습니다.
- **대타 모집 편의성 향상:** 모집 조건과 지원 내역을 한곳에서 관리하고, 평가 기록을 이후 모집의 참고 정보로 활용할 수 있습니다.
- **학습 및 교류 지원:** 시험 정보와 커뮤니티를 통해 자격 취득 경험과 자료를 공유할 수 있습니다.

### 데이터 해석 범위

- 자격 취득 건수는 실제 활동 중인 지도자 수와 다릅니다. 프로그램 대비 자격 취득 비율만으로 실제 인력 부족·과잉을 확정할 수 없습니다.
- 시연용 합성 신청 데이터는 실제 기관 운영 실적이 아니며, 성과 측정에서 제외해야 합니다.
- 추천은 탐색을 돕는 참고 정보이며 실제 채용이나 자격 취득을 보장하지 않습니다.

## 3. 기술 스택

현재 소스와 의존성 설정에서 확인되는 기술을 정리했습니다.

| 구분 | 사용 기술 | 활용 |
|---|---|---|
| 언어 | Python, JavaScript, HTML, CSS | 서버 로직 및 웹 화면 구현 |
| 웹 프레임워크 | Django | URL 라우팅, 모델, 폼, 템플릿, 관리자 기능 |
| UI | Django Templates, Bootstrap | 페이지 구성 및 반응형 레이아웃 |
| 시각화 | Chart.js | 통계 차트 표현 |
| 데이터베이스 | SQLite, PostgreSQL | 기본 서비스 데이터, 별도 커뮤니티 데이터 저장 |
| 데이터 처리 | pandas, openpyxl | CSV·XLSX 데이터 처리 |
| 외부 정보 수집 | requests, BeautifulSoup | 자격·시험 관련 정보 수집 |
| 외부 서비스 연동 | Gemini API, Kakao Maps JavaScript API | AI 교재 추천, 기관 위치 안내 |
| 실행·정적 파일 구성 | Gunicorn, WhiteNoise | 서버 실행 및 정적 파일 제공을 위한 구성 |
| 환경 설정 | python-dotenv | 환경 변수 로딩 |
| 소스 관리 | Git, GitHub | 버전 관리 및 저장소 공유 |

외부 API 기능은 키 설정과 외부 서비스 응답에 영향을 받습니다. 위 실행 구성은 의존성과 설정 기준이며 실제 배포 완료를 의미하지 않습니다.

| 대타 모집 | CenterContact, Posting, PhoneIdentity, Application, ReputationRecord | 담당자, 공고, 지원자, 지원, 평가 관리 |
| 커뮤니티 | Post, Comment | 게시글 및 댓글 관리 |
| 사용자 참조 | User | 평가 기록의 관리자 처리 참조 |

`Program`과 `ProgramCleanup`은 일대일 관계이며, 프로그램별 정리 결과는 없거나 하나입니다. 커뮤니티는 별도 PostgreSQL을 사용하며, 맞춤 추천 앱은 자체 모델 없이 기존 분석 데이터를 활용합니다.

## 7. 주요 프로시저

이 문서의 프로시저는 DB 저장 프로시저가 아닌 주요 기능의 처리 흐름을 뜻합니다.

### 7.1 데이터 입력 및 정제

1. CSV·XLSX 원본 데이터의 형식과 항목을 확인합니다.
2. 지역·종목 등 비교에 필요한 값을 정규화하여 저장합니다.
3. 프로그램을 기준 종목과 매칭하고 매칭 등급·근거를 기록합니다.
4. 운영 상태와 분석 활용 가능 여부를 정리합니다.
5. 정리된 정보를 프로그램 조회·지역 비교·추천에 활용합니다.

### 7.2 맞춤 추천

1. 사용자가 자격 보유 여부를 선택합니다.
2. 보유 자격 또는 관심 종목과 희망 지역 등의 조건을 입력합니다.
3. 운영 중이고 분석에 사용할 수 있는 프로그램을 대상으로 후보를 구성합니다.
4. 종목·지역·대상과 신청 현황 등 조건을 바탕으로 점수를 계산합니다.
5. 기관 또는 자격 방향과 함께 추천 근거·참고 지표를 보여줍니다.

추천은 가중치 기반 점수 계산을 사용하며, AI 교재 추천 기능과 별개입니다. 추천 결과는 별도 모델에 저장하지 않고 화면에 제공합니다.

### 7.3 지역별 프로그램·자격 취득 비교

1. 사용자가 지역과 종목 조건을 선택합니다.
2. 해당 조건의 운영 프로그램 수와 자격 취득 건수를 집계합니다.
3. 프로그램 대비 자격 취득 비율을 계산하여 비교합니다.
4. 프로그램이 없는 경우 비율을 계산 불가로 표시합니다.

### 7.4 대타 모집 및 지원

1. 기관 담당자가 본인 확인 절차를 거쳐 모집 조건을 등록합니다.
2. 지도자가 공고 상세 정보를 확인하고 지원합니다.
3. 시스템이 지원자의 전화번호 신원 정보와 중복 지원 여부를 확인합니다.
4. 담당자가 관리 화면에서 지원 내역을 확인합니다.
5. 근무에 대한 평가를 기록하고 이후 모집의 참고 정보로 활용합니다.

### 7.5 시험 정보 및 커뮤니티

1. 사용자가 자격·시험 일정 정보를 확인합니다.
2. 필요한 경우 AI 교재 추천 기능을 이용합니다.
3. 커뮤니티에서 질문과 자료, 준비 경험을 공유합니다.
